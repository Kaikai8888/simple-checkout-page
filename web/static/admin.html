Demo 後台調整商品價格 / 庫存商品列表
需要管理員帳號才能使用後台。以管理員登入
開著結帳頁，在這裡改價格或庫存，再回到結帳頁送出訂單，就能示範「價格變動 / 庫存不足」的流程。 更新會先寫 DB，在 commit 前同步 Valkey（商品 cache 與搶購閘門），兩者都成功才算成功。
ID商品類型價格實際庫存可售結帳中預留限量搶購

實際庫存：尚未成為訂單的庫存（建立訂單時扣除）。修改時，「可售」會跟著同樣幅度調整，結帳中預留的數量不受影響。
可售：顧客還能買的數量 ＝ 實際庫存 − 結帳中預留。送出訂單時在 PostgreSQL 直接扣這個欄位。
限量搶購：打勾的商品，送出訂單時會先經過 Valkey 閘門，擋掉超額的流量，避免大量請求同時搶同一列 DB 資料。
